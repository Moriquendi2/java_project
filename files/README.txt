This folder is reserved for runtime configuration, data, and resources when the
parking application needs them. The initial Swing shell has no external runtime
resource dependency. Keep future resource paths relative to the project package.

database.properties and set local MySQL connection values. The local file is
ignored by Git and should not contain credentials in shared submissions.
