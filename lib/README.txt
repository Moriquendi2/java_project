mysql-connector-j-9.7.0.jar is the project's MySQL JDBC driver. It supports MySQL
Server 8.0 and newer and runs on JRE 8 or newer, so it is compatible with this
project's JDK 21 and the local MySQL Server 8.0.46.

Swing and the JDBC API are part of the JDK. Do not add separate UI or JDBC API JARs.
Add other external JARs only when a concrete feature requires them.
